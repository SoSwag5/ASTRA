Early beta · 1.1.0-beta.1 · Windows x64

You have already downloaded the app. Finish these three steps:

  1. Install Python once

    If Python 3.13 is missing, open the official Python download page. Under Files, choose Windows installer (64-bit). Keep the Python launcher enabled, then return here.

  2. Double-click Install ASTRA.bat

    Find it in this folder. Keep its window open until it says Ready. Internet is needed to install the checked packages. This may take several minutes.

  3. Double-click Open ASTRA.bat

    Your browser opens your local workspace. Try the fictional demo first. Then choose your career focus, upload a text PDF CV, review and correct its facts, and confirm them.

Apply on the employer's website yourself. Gmail and AI are optional. No Git, Node or paid AI account is needed for this release.

Full guide and troubleshooting · Release notes and checksums

Keep ASTRA in a local folder outside cloud sync. It runs only on your computer; do not expose it online. This beta uses Python and is not a standalone signed Windows installer. Close it with stop.bat. If a check fails, keep the error and follow the guide—never disable security software. Public bug reports must use fictional information.
