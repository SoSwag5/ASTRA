## What changed

Rule-based matching is recommended/default; optional AI remains in advanced
Settings and is absent from beginner setup. Five-step setup displays the actual
extracted CV facts for correction/confirmation, explicitly skips optional Excel
import and requires deliberate saved career focus. Custom-only roles avoid
inherited technical targets, and CV keywords do not automatically select tracks.

Start scanning is clearer, keeps preview/confirmation/Stop and refreshes results
after completion. The normal launcher opens the owner's workspace, and the demo
offers Use my own CV. PDF reading order/common headings, decoded PDF object-policy
checks, legacy-PDF download checks and default browser-origin mutation restrictions
were corrected. Customer instructions and technical claims match the beta boundary.
