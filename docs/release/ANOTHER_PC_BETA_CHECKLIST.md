# ASTRA beta — test on another Windows PC

**Status: NOT RUN on the Owner's brother's computer.** Use the exact public
beta ZIP, not a developer folder or copied virtual environment. This checklist
is for the person at that computer; it does not authorize remote access or mail sync.

Record: beta version, ZIP SHA-256, Windows version, Python version, date,
installation duration, and PASS/FAIL for each step. Do not include personal paths.

1. Download the built ZIP from the official release. Compare its checksum with
   the release's `.zip.sha256` file. Extract All into a new local folder outside cloud sync.
2. Follow START HERE.html without help from a developer. Install official Python
   3.13.16 if needed. Record any confusing instruction or missing prerequisite.
3. Run Install ASTRA.bat as a normal user. Confirm it reaches Ready. Do not
   disable security software or bypass hash failures.
4. Run Open ASTRA.bat. Confirm localhost opens, the workspace is empty, and
   the fictional demo works. No nearby CV or spreadsheet should be imported.
5. Check light/dark appearance, a narrow window, keyboard focus and reduced
   motion. Confirm buttons, loading, empty and error states remain understandable.
6. Upload a made-up text PDF CV from a different major. Correct omissions and
   confirm only accurate facts. A scanned/image PDF should fail clearly or require
   correction; no previous confirmed facts should be silently overwritten by failure.
7. Record a fictional application, stop using this folder's stop.bat, reopen,
   and confirm the record survives. Remove it using the app's normal controls.
8. Optionally, with the tester's deliberate approval, preview one small public
   discovery scope, start manually and stop. No scheduled or startup scan should run.
9. Keep Gmail disconnected and AI off for this first acceptance run. There is
   no need to use a real CV, mailbox or payment method.
10. Stop the app, back up any needed local data, remove the disposable test
    folder and confirm the app is no longer listening. Keep useful failure evidence
    fictional and sanitized when reporting it.

Do not claim another-PC acceptance until a human completes this checklist.
Hosted clean Windows installation is separate automated evidence; it cannot
measure whether a novice understood the instructions.
