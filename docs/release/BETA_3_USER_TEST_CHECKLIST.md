# Test ASTRA beta3 — simple checklist

Use the [published beta3 ZIP](https://github.com/SoSwag5/ASTRA/releases/download/v1.1.0-beta.3/astra-1.1.0-beta.3.zip),
extract it into a new folder and follow [Start here](../GETTING_STARTED.md).
Open **Open ASTRA.bat** from that folder each time. **http://localhost:8787/**
shows whichever copy is running, so stop an older copy through its own stop.bat
before opening the new one. A browser tab alone does not identify the version.

- [ ] Open: no demo jobs/follow-ups and no scan starts by itself.
- [ ] Upload a CV: name, education, skills and experience match the original.
      Correct omissions before confirming.
- [ ] Setup: confirmation stays visible; optional tracker can be skipped;
      target jobs save. Start with rule-based matching.
- [ ] Sources: try one government, hospital and job-portal link. Recorded check
      dates do not guarantee current vacancies.
- [ ] Preview: press Start scanning now, review the sources and Cancel. No scan starts.
- [ ] Scan: when you choose, preview again and confirm. Progress is understandable
      and it finishes or explains an error. Zero suitable jobs can be a coverage limitation.
- [ ] Results: inspect up to ten jobs for role, country, seniority, eligibility and working link.
- [ ] Manual job: add public details from another website, prepare documents
      and check every statement. Submit yourself only when you choose.
- [ ] Interface: switch pages and Progress dates, open panels, try both themes
      and a narrow window. Choose Appearance -> Full motion for animations;
      Reduce motion should keep every action usable.
- [ ] Save/reopen: stop, reopen, restart Windows and reopen. Saved information remains.

Record **PASS / FAIL / NOT TESTED**. For a problem, write what you clicked,
what you expected, what happened and any error. Cover private details in screenshots.

The Owner plans own-PC testing now and another-PC testing after final v1.1.
Another-PC acceptance remains NOT RUN; it must not be presented as passed.
Gmail/account checks can be guided separately. This checklist does not close issue #48.
