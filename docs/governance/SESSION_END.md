Before handing off:

- [ ] Confirm the working tree is clean or list every intentional uncommitted
      file.
- [ ] Confirm no private records, credentials, local paths, or live user data
      entered public artifacts.
- [ ] Update `PROJECT_STATE.md` if its branch, release, risk, or hosted-state
      snapshot changed materially.
- [ ] Link evidence to the exact source SHA and artifact digest.
- [ ] State whether the outcome is READY FOR OWNER REVIEW, BLOCKED, or ongoing.
